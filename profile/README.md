## 📖 About

**Revite Revived** is an **unofficial revival project** of the original **Revite** client created by **Stoat** (formerly **Revolt**).

Our goal is not just to bring Revite back — but to **push it further** and see what it could've been!

We aim to:
- Restore and improve the original Revite experience
- Reach **feature parity** with the new **Stoat** client
- Introduce **exclusive features** unique to Revite Revived

---

## 🎯 Project Goals

| Goal | Description |
|----|------------|
| 🔁 Revival | Bring back the original Revite client |
| ⚖ Feature Parity | Match core Stoat client functionality |
| ✨ Enhancements | Improve UX, performance, and stability |
| 🧪 Exclusives | Add features not found in Stoat |
